Privacy policy: ScriptSense Rx Inbox Processor

Last updated: 23 October 2026

The ScriptSense Rx Inbox Processor ("the extension") is a Chrome extension for pharmacists who use ScriptSense. It helps work through the prescriptions in their ScriptSense inbox. This policy explains what it handles.

The short version

  • The extension runs in your browser. We operate no servers for it.
  • It has no analytics, no advertising and no tracking, and it loads no remote code.
  • It works only on the ScriptSense app (scriptsense.co.nz) and nothing else.

What the extension handles

  • Prescription and patient information shown in the ScriptSense app, which can include patient names, medicines, quantities and funding details. It is read from the ScriptSense page and from the ScriptSense API so that a dispense can be prepared, and it is used only for that.
  • The signed-in user's ScriptSense access token. The extension reads it from the ScriptSense page so it can call the ScriptSense API as the user who is already signed in. It is kept in the browser's memory only. It is never saved, logged, displayed or sent anywhere except to the ScriptSense API.
  • Staff details: the signed-in pharmacist's name, staff ID, roles and HPI CPN if available, recorded in the extension's activity log as the person responsible for a session.

What the extension stores

In the user's own browser only (Chrome's extension storage):

  • the pharmacist's rule choices and settings;
  • an activity log of what the extension did (Rx numbers, medicine names, outcomes and reasons, times, and the pharmacist responsible), and a record that the production notice was accepted for each session;
  • short-lived run state in the browser session, which is cleared when the browser closes.

The activity log can be exported by the user to a file in their Downloads folder. The extension never sends it anywhere.

Where information goes

  • To the ScriptSense API (api.prd.scriptsense.co.nz) that the user is already signed in to, to read prescription details and, for a small number of actions the user has switched on (marking an earlier prescription item inactive, moving an inbox item to a folder), to record a change in the same system. Dispenses themselves are submitted through the ScriptSense dispense form, exactly as if the pharmacist had pressed its Submit button.
  • To the print service on the user's own computer (localhost) when the extension prints a summary report or a label.

It is not sent to advertisers, analytics services or any other third party. The extension has no analytics, no tracking, and no remote code.

What we do not do

We do not sell or share this information, we do not use it for anything other than preparing and recording the user's own dispensing work, and we do not use it for advertising, credit or lending decisions.

Keeping it safe

The extension works only on the ScriptSense app and has no access to other websites. Only a signed-in user with the Pharmacist role can switch automatic processing on, and the user can stop it at any time. Everything it does is recorded in the activity log.

Your choices

Uninstalling the extension removes everything it stored in the browser. The activity log keeps only the most recent entries (the newest 200 and 50 sessions) and older ones are dropped automatically.
